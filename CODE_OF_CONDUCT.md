# Code of Conduct

## Our pledge

We want KAYENN to be a place where engineers, programmers and students can work together in a friendly and
professional way, regardless of age, gender, origin, experience, religion or views.

## Expected behaviour

- Be respectful and patient, especially with beginners.
- Criticise the code, the calculation or the idea – never the person.
- Assume good intentions; ask when something is unclear.
- Give concrete, verifiable information (clause of the code, example file, steps to reproduce).

## Unacceptable behaviour

- Insults, harassment, discrimination, personal attacks.
- Publishing someone's private data without permission.
- Spam, advertising and trolling.

## Enforcement

The maintainer may edit, hide or delete comments, issues and pull requests that break these rules, and may
block repeat offenders. Report a problem by contacting the maintainer through the GitHub profile
(<https://github.com/damiankozuszek>) or a private security advisory in this repository.

This Code of Conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/) (v2.1).
