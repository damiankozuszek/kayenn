# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for a security problem (e.g. a way to run code through a crafted `.kayenn`
file, a problem in the installer or in the update check). Use GitHub's private reporting:
**Security → Report a vulnerability** in this repository. You will get an answer as soon as possible.

## Calculation errors

A wrong calculation result is **not** a security issue – please open an ordinary
[issue](../../issues/new/choose) with the clause of the code and, if you can, an example project.
