# KAYENN fonts

The program uses its own fonts (shipped with the package) so that it looks the same on Windows, macOS and Linux:

| File | Family | Use |
|---|---|---|
| `NotoSans-*.ttf` | Noto Sans | the whole interface, reports, labels on the 3D model |
| `NotoSansMono-*.ttf` | Noto Sans Mono | numeric fields |
| `NotoSansSymbols2-Regular.ttf` | Noto Sans Symbols 2 | symbols ⚠ ⠿ ▸ ▾ |
| `NotoSansMath-Regular.ttf` | Noto Sans Math | symbols ⌀ ∝ ⟂ ≤ ≥ |

Source: the Noto project (github.com/notofonts), SIL Open Font License 1.1 – `OFL.txt`.
