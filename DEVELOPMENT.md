# KAYENN – information for developers

The project language (code, comments, documentation, commit messages) is **English**. The program interface,
reports, printouts and the material database are in **Polish** – keep them that way unless a new interface
language is being added.

## Running from source

Python 3 and PySide6 (with QtWebEngine – for the map) are required:

```
py -m pip install PySide6
py kayenn.pyw
```

On Windows a double-click on `kayenn.pyw` is enough (macOS / Linux: `python3 kayenn.pyw`). When
PySide6 is missing, the program offers to install it on the first start.

## Tests

```
py tests.py                     # full suite (about 1 min)
py tests.py --quick             # one 3D view
py tests.py --screenshots DIR   # window screenshots to look at
```

Exit code 0 = no errors. Run the tests after every change.

## Installation packages

GitHub Actions (`.github/workflows/packages.yml`) builds the packages on Windows, macOS and Linux: tests,
PyInstaller, a trial run of the built program (window screenshots as the `screenshots-<system>` artifact), package.

- Locally: `python packaging/build.py` (requires `pip install -r packaging/requirements.txt`; Windows – Inno Setup 6).
- New release: change `APP_VERSION` in `kayenn.pyw` and push a `v<version>` tag – the packages go to a draft
  release in the Releases tab.

## Look on different systems

The program uses its own fonts (Noto, `fonts/` folder), the Fusion style, its own light palette and font sizes
computed as at 96 dpi – so it looks the same on every system.

## Structure

The part names are internal – the user sees only the name **KAYENN**.

| Part | Scope |
|---|---|
| **KAYENN Manager** | main window: project, list of cases, printout, language menu |
| **KAYENN Codes** | code loads: imposed, snow, wind |
| **KAYENN Lab** | own loads, material database (`kayenn_materialy.txt`) |
| **KAYENN FEM** | finite element analysis (planned) |

| Folder / file | Contents |
|---|---|
| `kayenn.pyw` | the whole program |
| `tests.py` | automated tests |
| `kayenn_materialy.txt` | bundled material database (Polish, user-editable) |
| `fonts/` | bundled Noto fonts (OFL) |
| `branding/` | wordmark and icon, generated by `branding/branding.py` |
| `packaging/` | PyInstaller spec, Inno Setup script, build script |
