# Czcionki programu KAYENN

Program używa własnych czcionek (dołączonych do pakietu), żeby wyglądał tak samo w Windows, macOS i Linuksie:

| Plik | Rodzina | Zastosowanie |
|---|---|---|
| `NotoSans-*.ttf` | Noto Sans | cały interfejs, raporty, opisy na modelu 3D |
| `NotoSansMono-*.ttf` | Noto Sans Mono | pola liczbowe |
| `NotoSansSymbols2-Regular.ttf` | Noto Sans Symbols 2 | symbole ⚠ ⠿ ▸ ▾ |
| `NotoSansMath-Regular.ttf` | Noto Sans Math | symbole ⌀ ∝ ⟂ ≤ ≥ |

Źródło: projekt Noto (github.com/notofonts), licencja SIL Open Font License 1.1 – `OFL.txt`.
